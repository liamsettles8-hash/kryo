# KRYO

Official website for the KRYO Minecraft server.

**Server IP:** `kryo.cs2.my`

## GitHub Pages

1. Open the repository settings.
2. Go to **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save.

The site is a static HTML/CSS/JavaScript website and needs no backend.
